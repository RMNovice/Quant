可以立即开展云端DEV-01工程骨架、DEV-02模型/契约、离线数据与引擎开发；数据采购和网站正式部署待用户决定，真实数据依赖按任务表明确管理。DEV-01的云端完成标准见补充规范，不再以用户Windows本机能启动作为门槛。

开发人员首先将本文档任务拆入工作清单，保留需求编号；依赖选型锁版、真实源映射、历史规则来源等工程调查按DEV任务完成，不需向用户重新询问已给出的默认值。涉及费用、真实数据采购及外部开放访问时仍需取得具体决定。

v0.1保留历史参考，不作为当前计算与接口规范。所有新增范围和语义调整同步更新四份文档、Schema、示例与验收映射；不得仅在代码中改变交易含义。
